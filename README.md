# Excel VBA Data Cleaning System

### Automated Data Cleaning and Data Quality Validation Using Microsoft Excel VBA

## Project Overview

This project focuses on identifying and organizing messy raw data using Microsoft Excel and VBA automation.

The practice dataset contains 100 records and 8 columns. It includes misplaced values, missing information, inconsistent data positions, and data quality issues.

The objective is to transform unorganized raw information into a structured dataset that is easier to analyze and manage.

## Project Objectives

- Identify misplaced data across multiple columns.
- Recognize different types of information.
- Reorganize data into the correct structure.
- Identify missing and incomplete information.
- Generate a structured cleaning report.
- Improve data quality and organization through automation.

## Dataset Information

| Field | Description |
|---|---|
| Order ID | Unique order identification |
| Order Date | Date of the transaction |
| Customer Name | Customer information |
| Product | Product name |
| Category | Product category |
| Quantity | Number of items ordered |
| Unit Price | Product price in PKR |
| Region | Sales location |

**Dataset Size:** 100 Rows × 8 Columns

## Project Workflow

1. Import and inspect raw data.
2. Identify misplaced information.
3. Classify data using VBA.
4. Reorganize recognized values.
5. Validate missing information.
6. Generate a clean data worksheet.
7. Create a cleaning report for manual review.

## Expected Project Outputs

**1. Raw Messy Data**

Original dataset containing data quality problems.

**2. Clean Data**

A reorganized dataset with information placed in the appropriate columns wherever it can be identified.

**3. Cleaning Report**

A report identifying records that are clean or require manual review.

## Important Notes

The uploaded Excel workbook contains the raw practice dataset. The VBA automation code is maintained separately and must be added to a macro-enabled `.xlsm` workbook to execute the cleaning process.

The automation is designed for the known practice dataset and product catalogue. Missing or ambiguous information may require manual verification.
